# 🎬 MovieGO

Aplicativo mobile desenvolvido em **React Native**, utilizando a API da **TheMovieDataBase (TMDB)** para exibição de informações sobre filmes.  
Armazena dados locais com **AsyncStorage**.

## ⚙️ Tecnologias Utilizadas

- 📱 **React Native**
- ☁️ **TheMovieDatabase API (TMDB)**
- 💾 **AsyncStorage**

---

## 🔧 Funcionalidades

- 👤 **Criação de conta**
- 🖼️ **Personalização da imagem de perfil**
- 🎞️ **Visualização de filmes por categorias**
- 🔍 **Busca de filmes por palavras-chave**
- 🎥 **Detalhamento completo do filme**, incluindo:
  - Título
  - Ano de lançamento
  - Diretor
  - Duração
  - Sinopse
  - Avaliação
  - Elenco
  - Capa do filme e pôster de fundo
- 🙋 **Visualização do perfil do usuário**
